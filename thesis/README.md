# Master's Thesis: Audio Signal to Sheet Music Conversion

This project is part of my master's thesis, focusing on converting audio signals into sheet music/tab notation. The project is configured to work with **Visual Studio Code** and the **LaTeX Workshop** extension.

## Requirements

- [Visual Studio Code](https://code.visualstudio.com/)
- A LaTeX distribution (e.g., [MikTeX](https://miktex.org/) for Windows, [MacTeX](https://www.tug.org/mactex/) for macOS, [TeX Live](https://www.tug.org/texlive/) for Linux)
- The [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) extension for VS Code
